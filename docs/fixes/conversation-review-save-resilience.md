# تقييم المحادثات — مسار حفظ سريع ومقاوم للتكرار

- هوية المراجع تُربط من جلسة المستخدم على الخادم قبل RLS.
- ضغط الحفظ المتكرر أثناء نفس العملية محجوب محليًا.
- إذا حفظ الخادم التقييم وانقطع الرد أو أعاد المستخدم المحاولة، يتم استرجاع نفس التقييم بدل إنشاء نسخة ثانية.
- أثر النقاط يستخدم `source_record_id = review_id` ومسار V3 idempotent؛ لا تتكرر حركة النقاط لنفس التقييم.
- إذا فشل ربط النقاط بعد نجاح حفظ التقييم، تظل المسودة ولا تعتبر العملية مكتملة؛ إعادة الحفظ تستكمل الربط على نفس التقييم.
- الأعمال غير الحرجة (سجل النشاط، الإشعار، متابعة الجودة، تحديث السجل) لا تعطل زر الحفظ الرئيسي.
- سجل التقييمات الكامل لا يعاد تحميله بعد كل حفظ عند العمل في شاشة إضافة تقييم جديد.
